# Gmail OTP Copier

Chrome, Edge, and Brave extension that reads verification codes from one or more Gmail accounts. For each new code it can auto-fill the page, copy the code, or only keep it in the popup. Nothing is hosted: mail is read in the browser with the Gmail readonly scope.

See [SETUP.md](SETUP.md) for the Google Cloud project, test users, and how to install it unpacked.
