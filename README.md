# Keytray

Chrome, Edge, and Brave extension that reads verification codes from Gmail accounts. One account is free. A one-time purchase unlocks more. For each new code it can auto-fill the page, copy the code, or only keep it in the popup. Mail is read in the browser with the Gmail readonly scope. Checkout for extra accounts is ExtensionPay and Stripe.

See [SETUP.md](SETUP.md) for the Google Cloud project, test users, and how to install it unpacked. It is not published in an extension store.

You can remove the purchase code and build a copy for yourself. Selling it, charging for a copy, or profiting from it is reserved to the author. See [LICENSE](LICENSE).
