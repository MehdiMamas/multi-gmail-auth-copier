Gmail OTP Copier

A browser extension for Chrome, Edge, and Brave that reads verification codes from one or more Gmail accounts you connect. For each new code it can fill the page, copy the code, or only keep it in the popup.

Nothing is hosted. The extension talks to Gmail from your browser with the Gmail readonly scope. Email bodies are used to find a code and are not saved. Stored items are the code, sender, subject, and time, kept in this browser only.

What it does

  • Connect more than one Gmail account and list recent codes in the popup.
  • Check for new codes in the background, or sync on demand.
  • Auto-fill a code field, copy the code, or do nothing, per account.
  • Show a Fill chip on a detected code field when a recent code is stored.

Google access

Sign-in uses Google OAuth. The extension requests https://www.googleapis.com/auth/gmail.readonly and https://www.googleapis.com/auth/userinfo.email. It does not send, delete, or modify mail. You can disconnect an account in the extension settings and revoke access in your Google Account permissions.
